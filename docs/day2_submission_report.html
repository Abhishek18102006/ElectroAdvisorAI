2. Complete 12-Endpoint REST API Architecture

The API specification was upgraded to handle real-world e-commerce edge cases, hybrid UI controls, and system observability:

Domain Method Endpoint Engineering Justification
Catalog GET /api/v1/products Deterministic pagination (order_by(Product.id.asc())), price bounds, and brand filters.
Catalog GET /api/v1/products/{product_id} Full product details, specs, intended uses, pros, and cons.
Catalog GET /api/v1/products/compare UX Enhancement: Side-by-side spec matrix and dynamic trade-off highlights for chosen products.
Catalog GET /api/v1/categories UI Optimization: Distinct categories, counts, price ranges, and brands to populate UI filter chips.
Agent POST /api/v1/conversations Initialize a new stateful customer sales consultation session.
Agent POST /api/v1/conversations/{id}/messages Process customer natural language input through decision orchestrator; validates empty/whitespace.
Agent GET /api/v1/conversations/{id} Retrieve chat history, extracted requirements, and memory state.
Agent PUT /api/v1/conversations/{id}/requirements Hybrid UI Override: Allows UI sliders and chips to update constraints directly without typing in chat.
Agent DELETE /api/v1/conversations/{id} Privacy & Reset: Cascades deletion of conversation messages and state from SQLite.
Agent POST /api/v1/conversations/{id}/feedback Product Analytics: Record user sentiment (thumbs up/down) and purchase conversion intent.
System GET /api/v1/health Service uptime, database connection verification, and active product count.
System GET /api/v1/conversations/{id}/debug Engineering Rigor: Exposes internal constraints, rejection summaries, and candidate score breakdowns.

3. Resolution of Critical Bugs & Reliability Hardening

All 11 reliability bugs identified during technical review were confirmed with targeted tests and resolved in production code:

Bug & Subsystem Root Cause & Solution Verification
1. Indian Currency Parsing
extractor.py		 ₹1,20,000 was misparsed as 20,000 because regex expected only 3-digit comma groups. Updated regex to (?:₹|rs\.?|inr)?\s*(\d{1,3}(?:,\d{2,3})+|\d{4,7})\b and stripped commas before float conversion. test_indian_number_format_parsing
2 & 3. Cloud GPU Relaxation & Scenario D
state.py, orchestrator.py		 ML previously locked requires_gpu=True permanently. Now, answering "cloud" relaxes GPU requirement to False and resets RAM. Scenario D uses structured state flag asked_ml_env instead of fragile string matching. test_cloud_relaxes_gpu_requirement
4. Substring Boundary Mismatches
extractor.py		 "Headphones" was classified as "phone", "html" matched "ml", and "portable" matched "tab". Added strict \b regex word boundaries across all keywords and acronyms. test_substring_matching_bugs
5. Category Spec Isolation
state.py, filter_rank.py		 "Programming" previously added min_ram_gb=8, causing monitor queries to fail. Hardware checks are now strictly scoped to laptops, and switching categories flushes obsolete hardware constraints. test_category_switch_clears_hardware_constraints
6. Top-2 Diversity Selection
filter_rank.py		 Diversity rule previously checked abs(w1 - w2) >= 0.4 without direction, selecting the heavier Dell G15 over lighter ASUS TUF. Now enforces that if portability is requested, candidate 2 must be lighter than or equal to candidate 1. test_top2_selection_for_portability_does_not_pick_heavier_worse_laptop
7. Dynamic Trade-Off Generation
explainer.py		 Replaced hardcoded template lines with dynamic delta comparisons across compute, weight, battery, and price. Added category-specific trade-offs for non-laptop devices. test_conversation_flow.py
8. Database-Driven No-Match
explainer.py		 Eliminated hardcoded ₹74,990 text. Dynamically queries SQLite for the cheapest compliant item and calculates the exact gap against customer budget. test_impossible_constraints_honest_no_match
9. Greeting Prefix Misfire
orchestrator.py		 "High-end laptop" was treated as "hi". Punctuation is stripped and compound words starting with "hi" are exempted from greeting triggers. test_greeting_does_not_misfire_on_highend_laptop
10. Gaming Dedicated GPU Enforcement
filter_rank.py		 Gaming strictly enforces requires_dedicated_gpu=True, correctly disqualifying Apple unified memory for Windows/DirectX gaming workflows. test_hard_constraint_ram_and_gpu
11. Post-Recommendation Follow-ups
orchestrator.py		 Added intent handlers for post-recommendation gratitude ("thanks") and refinements ("any lighter options?"), preventing recommendation loop repetition. test_post_recommendation_intents
